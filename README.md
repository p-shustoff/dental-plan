# План лечения на снимке

Страница для стоматолога: загрузить снимок, кликом отметить зубы, расписать работы и стоимость и выгрузить лист для пациента в PDF или PNG.

Работает целиком в браузере и без интернета. Сервера нет, сборки нет.

## Запуск

Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari). Папки `fonts/` и `vendor/` должны лежать рядом.

Можно опубликовать через GitHub Pages: Settings → Pages → ветка `main`, папка `/ (root)`.

## Как пользоваться

1. Загрузите снимок: кнопкой, перетаскиванием или вставкой скриншота (`Ctrl+V`). Подходят PNG и JPG. DICOM не открывается: сделайте скриншот нужного ракурса в программе просмотра КЛКТ.
2. Кликните по зубу на снимке и выберите номер по зубной формуле FDI. Появятся метка и строка в таблице.
3. Точку и номер можно перетаскивать. `Delete` удаляет выбранную метку.
4. Впишите работу, цену и комментарий. Если работа есть в прайсе («Мой прайс» внизу), цена подставится сама.
5. «Скачать PDF» сохраняет лист с выделяемым текстом, «Скачать PNG» — одну картинку.

## Где хранятся данные

Только в браузере пользователя. Черновик со снимками лежит в IndexedDB, прайс в localStorage. На сервер ничего не отправляется. На другом компьютере или в другом браузере черновика не будет.

Не коммитьте снимки и выгруженные листы: это персональные данные пациентов. `.gitignore` уже исключает изображения, PDF и DICOM.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | разметка |
| `styles.css` | стили и подключение шрифтов интерфейса |
| `app.js` | логика: снимки, метки, таблица, прайс, сборка листа |
| `fonts/` | Golos Text и IBM Plex Mono (woff2, латиница и кириллица) для интерфейса |
| `vendor/jspdf.umd.min.js` | [jsPDF](https://github.com/parallax/jsPDF) 2.5.1 |
| `vendor/pdf-fonts.js` | шрифты, встраиваемые в PDF; генерируется скриптом, вручную не редактировать |
| `tools/build-pdf-fonts.py` | пересобирает `vendor/pdf-fonts.js` |
| `LICENSES/` | лицензии сторонних файлов |

## Зависимости

Сторонние файлы лежат в репозитории, чтобы страница работала без интернета и без установки.

- **jsPDF 2.5.1** — `vendor/jspdf.umd.min.js`, лицензия MIT. Взят из npm-пакета `jspdf@2.5.1` (`dist/jspdf.umd.min.js`).
- **Шрифты интерфейса** — `fonts/*.woff2`, лицензия SIL OFL 1.1. Взяты из npm-пакетов `@fontsource/golos-text@5` и `@fontsource/ibm-plex-mono@5`.
- **Шрифты для PDF** — `vendor/pdf-fonts.js`, лицензия SIL OFL 1.1. Собираются из репозитория [google/fonts](https://github.com/google/fonts):

  ```bash
  pip install fonttools
  python3 tools/build-pdf-fonts.py
  ```

  Шрифты урезаны до латиницы, кириллицы и нужных знаков (₽, №, тире, кавычки). Символ вне этого набора, например эмодзи, в PDF не отобразится. Урезанный IBM Plex Mono переименован в «Dental Plan Mono»: имя «Plex» зарезервировано лицензией за оригиналом.

## Ограничения

- Валюта пока одна: рубли.
- Снимок с метками попадает в PDF картинкой; весь остальной текст выделяется и копируется.
- Файлы DICOM не поддерживаются.
